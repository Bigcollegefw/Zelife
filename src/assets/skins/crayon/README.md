# 蜡笔杂货皮肤 · 美术资源插槽

本目录 = crayon 皮肤的专属插槽。`SysSprite` 组件按「当前皮肤 → 本目录 → `assets/system/` 旧插槽 → 内置 SVG」的顺序探测，**放图即生效**，动画全部由代码驱动，美术只交静态图。

## 文件规范

| 文件名 | 必需 | 说明 |
|---|---|---|
| `sprite.png` | 是 | 主形象（待机）。**独立立绘**：无底板、无圆圈的透明全身立绘（QQ秀式屏幕小精灵），角色居中、四边留白均匀、脚部贴近下缘；512×512，角色占画面 ≥70%（缩小到 44px 停靠态仍可辨认） |
| `sprite-blink.png` | 否 | 眨眼帧：与主形象**同构图同大小**，只改眼睛（4.4s 周期自动眨） |
| `sprite-happy.png` | 否 | 开心表情：`mood='happy'` 时替换 |
| `sprite-sad.png` | 否 | 低落表情：`mood='sad'` 时替换 |

支持 `.webp`（同名替换，`sprite.webp`）。不要 JPG（无透明通道）。

> 2026-11-01 拍板：UI **不要描边**（断线蜡笔边框方案已废弃删除）——蜡笔感只靠色板 + 歪圆角 + 大色块平涂，本目录不再有边框贴片资产。

## 表情帧纪律（重要）

表情帧必须以**定稿主图**为参考图（`tools/gen-assets.mjs` 的表情槽位已这样接线），
保证构图、比例、色彩逐像素一致，只动五官。先定稿、后变体。

## 呈现方式（美术不用做，代码负责）

- 独立小精灵：投影按 alpha 自动贴合角色轮廓（不是圆形），像长在屏幕里自由活动
- 待机动画：呼吸起伏 + 轻微摇晃（绕脚跟为轴，纯 transform，飞行途中也在呼吸）
- choose 阶段：站卡沿——停靠在决策面板顶边中点，脚踩面板上沿
- announce 阶段：躲猫猫——下半身藏进气泡后，只露上半身探头
- 绕卡飞行/轨道/眨眼全部代码驱动，静态图直接继承

## 生成

`npm run assets` 看槽位报告；`node tools/gen-assets.mjs gen crayon-sprite` 生成。
提示词与质检清单见 `src/assets/asset_bible.md`。
