# 品牌资产插槽

## wordmark 字标

放一张 `wordmark.png`（或 `.webp`）到本目录，全站字标**自动换图**（`src/brand.js` 探测，无需改代码）：

- 触点：主页（IntroView）、关于页（AboutView）
- 没有图时回退衬线文本「择择人生」——所以随时可以只删图退回文本

### 规格

- 横版，**宽 ≥1200px**（按 2:1 或更扁），**透明背景**
- 内容：「择择人生」四个手写蜡笔字，牛仔蓝色，断线飞白笔触
- 字要经得起缩小到 ~180px 宽（主页展示宽度）
- 无英文、无标点、无描边、无投影

### 生成与质检

`node tools/gen-assets.mjs gen brand-wordmark` → `post` 落本目录。
**逐字核对**四个字（AI 中文字形易错：「择」的右部、「择择」二字相同但笔势应有手写差异感）。
完整规范见 `src/assets/asset_bible.md`。
