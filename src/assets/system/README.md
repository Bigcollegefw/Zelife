# 系统小人美术资源插槽

把做好的图放进本目录，`SysSprite` 组件会**自动检测并替换**内置占位小人，无需改任何代码。
动画（飞行轨迹、旋转、缩放、浮动、眨眼）全部由代码驱动，美术只需要交**静态图**。

## 文件规范

| 文件名 | 必需 | 说明 |
|---|---|---|
| `sprite.png` | 是 | 主形象（待机）。透明背景 PNG，建议 512×512（正方形），角色居中、四周留约 15% 空隙，占画面约 70%。深色底和浅色底都会出现，注意边缘干净 |
| `sprite-blink.png` | 否 | 眨眼帧：与主形象**同构图同大小**，只改眼睛（闭眼）。有它就以 4.4s 周期自动眨眼；没有则只有主形象静止 |
| `sprite-happy.png` | 否 | 开心表情：`mood='happy'` 时替换主形象（如结算播报好消息） |
| `sprite-sad.png` | 否 | 低落表情：`mood='sad'` 时替换主形象（如坏结果反馈） |

也支持 `.webp`（同名替换，如 `sprite.webp`）。不要用 JPG（无透明通道）。

## 表情帧使用（已预埋，放图即生效）

`SysSprite` 组件有 `mood` 属性（`idle` / `happy` / `sad`），有对应 PNG 才会切换，没图自动回退主形象。目前舞台固定传 `idle`；等表情图到位后在 `StageView` 里按结算的正负把 `mood` 传起来即可（一句话的改动）。

## 生成要点（AI 生图提示词收尾要求）

- 贴纸/扁平风，墨线描边，米白或透明底，**不要投影在图内**（代码会加统一 drop-shadow）
- 单个角色、居中、无文字、无边框、无背景装饰
- 造型要能承受缩小到 44px 仍可辨认（决策面板停靠态很小），细节别太密

## 动画分工（美术不用做）

- **绕卡螺旋飞行**（入场 → 贴卡一周 → 螺旋收进面板头部）：三层嵌套 `transform`（旋转/伸距/反旋），轨道几何由 JS 实测面板 DOM。整图变换，任何静态图直接继承
- 浮动呼吸：`spr-bob`
- 眨眼：`sprite-blink.png` 周期切换（4.4s 一轮）
- 表情切换：`mood` 属性驱动，换 `sprite-happy/sad.png` 整图替换
- 若以后想要"嘴动/挥手"等局部动画：交多帧图（`sprite-2.png`…），改 `SysSprite.vue` 里的帧切换逻辑即可，接入点已预留
