# 系统小人美术资源插槽

把做好的图放进本目录，`SysSprite` 组件会**自动检测并替换**内置占位小人，无需改任何代码。
动画（飞行轨迹、旋转、缩放、浮动、眨眼）全部由代码驱动，美术只需要交**静态图**。

## 文件规范

| 文件名 | 必需 | 说明 |
|---|---|---|
| `sprite.png` | 是 | 主形象。透明背景 PNG，建议 512×512（正方形），角色居中、四周留约 15% 空隙，占画面约 70%。深色底和浅色底都会出现，注意边缘干净 |
| `sprite-blink.png` | 否 | 眨眼帧：与主形象**同构图同大小**，只改眼睛（闭眼）。有它就以 4.4s 周期自动眨眼；没有则只有主形象静止 |

也支持 `.webp`（同名替换，如 `sprite.webp`）。不要用 JPG（无透明通道）。

## 生成要点（AI 生图提示词收尾要求）

- 贴纸/扁平风，墨线描边，米白或透明底，**不要投影在图内**（代码会加统一 drop-shadow）
- 单个角色、居中、无文字、无边框、无背景装饰
- 造型要能承受缩小到 44px 仍可辨认（决策面板停靠态很小），细节别太密

## 动画分工（美术不用做）

- 飞行路径 / 回摆落位 / 效果页起飞：CSS 关键帧，作用在整图 `transform` 上
- 浮动呼吸：`spr-bob`
- 眨眼：`sprite-blink.png` 周期切换（4.4s 一轮）
- 若以后想要"嘴动/挥手"等局部动画：交多帧图（`sprite-2.png`…），改 `SysSprite.vue` 里的帧切换逻辑即可，接入点已预留
