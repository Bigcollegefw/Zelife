# 场景照片

把你现实生活的照片放到这个文件夹，**文件名（去扩展名）等于场景 id** 即自动成为该场景背景：

| 文件名 | 场景 |
|---|---|
| `wake.jpg` | 08:30 清晨 · 卧室 |
| `breakfast.jpg` | 09:30 早晨 · 街道 |
| `afternoon.jpg` | 14:00 午后 · 房间 |
| `evening.jpg` | 19:30 傍晚 · 书桌 |
| `night.jpg` | 23:00 深夜 · 床边 |

支持 jpg / jpeg / png / webp / avif。竖构图效果最好。

不放照片也没关系——每个场景有默认的 CSS 渐变背景。
也可以在场景页里点「换上我的照片」临时试用（仅内存，刷新还原）。
